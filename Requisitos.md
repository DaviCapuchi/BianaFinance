


# O que eu quero com esse projeto?

Não estou fazendo esse projeto para vender e com o objetivo  de aprender Rust, Node(React, Typescript, tailwind), arquitetura de software e system design  

## Premissa

Software tem o objetivo simples  a sua função é um gerenciador de finanças normal onde a pessoa cadastra suas contas, objetivos financeiros e o software mapeia seus gastos gerando relatórios para ajudar na organização desses dados.
Seção de Investimentos e para servir exatamente como um Status Invest por
exemplo onde a pessoa consegue ver seus ativos e analisar e fazer comparações entre ações 

## Tecnologias
- Next.js
- Node
- Tailwind CSS
- React
- Typescript
- Rust


## Requisitos
- Princípios SOLID
- Minimo de acoplamento
- Arquitetura Monolítica
	- Simples de aprender


## Funcionalidades
- AUTH(JWT, HASH e Criptografia)
- Cadastro das contas
	- Valor
	- Se é recorrente
	- Categoria(Mercado, Contas de alguma loja, Comida,  outros)
---
- Código das Ações
	-  A montagem da carteira e contas de rentabilidade etc feita por Rust
